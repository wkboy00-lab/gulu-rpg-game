# 《咕噜远征团》 Gulu Expedition

原创 Q 版魔幻放置卡牌 RPG（单机网页版）。五人编队、阵营羁绊、确定性自动战斗＋手动大招、英雄养成、装备、招募双保底、挂机收益、迷雾远征、外观与赛季活动、模拟充值中心（免费模拟，非真实支付）。

> 本仓库为该游戏的源代码基准，供 Muse 与 ChatGPT 协作审核与开发。
> 线上可玩版本由 Muse 工件平台托管（工件 slug: `space`）。

## 技术形态（如实说明）

- **单文件静态网页应用**：全部游戏逻辑、UI 与样式都在 `index.html`（原生 JavaScript + HTML/CSS，无框架、无构建步骤）。
- **零依赖**：没有 package.json、没有第三方库、运行时不请求任何外部服务。
- **素材**：`assets/` 下的本地 `.webp` 图片（英雄/外观/敌人/Boss/场景），代码以文件名硬编码引用，请勿改名。
- **存档**：浏览器 IndexedDB（库名 `gulu-expedition`，schemaVersion=1），另支持设置页内 JSON 导出/导入。
- 任务书原定的 React+Phaser+TypeScript 架构未采用；本仓库以当前真实实现为准。

## 运行方式

任选其一：

1. 直接用浏览器打开 `index.html`（部分浏览器对本地文件的 IndexedDB 有限制，推荐方式 2）。
2. 静态服务器：`python3 -m http.server 8000` 后打开 `http://localhost:8000/`。
3. 部署到任意静态托管（GitHub Pages、Cloudflare Pages、Netlify 等），根目录即本站根目录。

无需安装、无需构建、无需注册即可游玩。

## 目录
