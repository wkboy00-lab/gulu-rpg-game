## 本地运行

直接用浏览器打开 `index.html` 即可游玩（单文件，无需构建、无外部资源）。
复现链：`index-round4-backup.html` → 运行 `build-home-v1.py` 得 city1 → 运行 `build-home-guild-v2.py` 得 city2 → 运行 `build-guild-v3.py` 得 city3 → 运行 `build-city4-core.py`、`build-city4-scene.py`、`build-city4-fix1.py`、`build-city4-fix2.py` 得 city4。构建脚本内含制作机绝对路径，异机复现时须先改路径；场景补丁另需本地素材（苔盾 5 层 WebP、石地裁切图，见“资源来源”）。复现链已验证：由 city3 备份重建的 city4 与交付文件字节一致（MD5 见上表）。

## 资源来源

全部图片取自本仓库根目录 `assets/` 的原始素材（本分支继承）：城市原画 `city.webp`、12 名英雄 WebP 立绘、敌人与 Boss 立绘、森林背景；单文件内已 base64 内嵌，不依赖外部文件。苔盾 5 个待机图层取自苔盾分层样片的原图像素拆分（身体/前腿/头/盾/持锤手），公会石地纹理取自城市原画的石板路裁切；角色、美术、名称均为咕噜原创；只借鉴了《我叫MT：崛起》公开玩法机制与系统结构，未复制其角色、美术、剧情、台词、代码与素材（见 `BORROWING_MAP.md`）。

## 存档隔离与兼容

- 预览只用浏览器 `localStorage`，正式键为 `gulu-mtstyle-v1`；不使用 IndexedDB，不使用 sessionStorage。`?savekey=` URL 参数可指定隔离测试键，不自动覆盖旧档。
- 原游戏用浏览器 IndexedDB，数据库名 `gulu-expedition`、对象存储 `save`，不使用 localStorage。
- 两者机制与名称完全不同：预览不读取、不写入原游戏存档。
- 旧档可直接加载（新增 `settings.reduceMotion` 默认 false）；新增的 `.prevgood` / `.corrupt.*` / `.preimport.*` 备份键均为加法，不影响旧档。坏档永不自动覆盖，须在设置页处理（导出 / 恢复 / 放弃）。
