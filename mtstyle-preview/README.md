## 本地运行

直接用浏览器打开 `index.html` 即可游玩（单文件，无需构建、无外部资源）。
复现链：`index-round4-backup.html` → 运行 `build-home-v1.py` 得 city1 → 运行 `build-home-guild-v2.py` 得 city2 → 运行 `build-guild-v3.py` 得 city3。构建脚本内含制作机绝对路径，异机复现时须先改路径。

## 存档隔离

- 预览只用浏览器 `localStorage`，键为 `gulu-mtstyle-v1`；不使用 IndexedDB，不使用 sessionStorage。
- 原游戏用浏览器 IndexedDB，数据库名 `gulu-expedition`、对象存储 `save`，不使用 localStorage。
- 两者机制与名称完全不同：预览不读取、不写入原游戏存档；设置页“清空本原型存档并重开”只删 `gulu-mtstyle-v1`。
