## 本地运行

- 直接用浏览器打开 `mtstyle-preview/index.html` 即可游玩，无需服务器（单文件，图片以 base64 内嵌，无外部请求）。
- 也可用静态服务器：`python3 -m http.server` 后访问对应路径。

## 资源来源

- 实际使用的图片（城市原画、12 名英雄、10 个敌人、4 个 Boss、森林背景）已全部以 base64 内嵌在 `index.html` 内，打开单文件即可完整显示。
- 原始素材文件在本仓库根目录 `assets/`（本分支继承自 main）：`assets/city.webp`、`assets/hero-*.webp`、`assets/enemy-e*.webp`、`assets/boss-b*.webp`、`assets/bg-forest.webp` 等。
- 构建脚本内引用了原制作机的绝对路径（交接包与工作目录），在其他机器复现时须先改路径；首选直接使用 `index.html`，复现链见下一节。

## 复现链（仅需复现时）

1. 把 `index-round4-backup.html` 拷为 `index.html`；
2. 运行 `build-home-v1.py`，得到 city1；
3. 运行 `build-home-guild-v2.py`（脚本会校验输入确为 city1 状态），得到 city2，即本目录的 `index.html`。
4. 构建脚本需要 Python 3 与 Pillow。

## 版本号查看

- 进入游戏后点右上角齿轮打开设置页，最下方“版本”面板显示 `2026.11.01-city2（主城 v2 · 公会大厅）`。
- 源码中搜索 `APP_VERSION` 或 `2026.11.01-city2` 亦可核对。

## 存档隔离

- 本预览只用浏览器 `localStorage`，键为 **`gulu-mtstyle-v1`**（常量 `SAVE_KEY`），代码中不使用 IndexedDB、不使用 sessionStorage。
- 原游戏存档在浏览器 IndexedDB，数据库名 **`gulu-expedition`**、对象存储 `save`，且不使用 localStorage。
- 两者存储机制与名称完全不同，**预览不会读取、不会写入原游戏存档**；清空预览存档（设置页“清空本原型存档并重开”）只删 `gulu-mtstyle-v1`。
