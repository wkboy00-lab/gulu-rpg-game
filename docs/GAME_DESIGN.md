# 玩法与系统（与当前实现一致）

## 核心

- 大陆：铃芽大陆。12 名英雄、4 阵营（森芽同盟/熔炉工坊/潮汐学会/星灯旅社）、6 职业。
- 阵营克制环：森芽→潮汐→熔炉→星灯→森芽，克制伤害 +15%。羁绊：同阵营 2 人生命 +5%，3 人生命 +10%/攻击 +5%，四阵营齐全队攻击 +5%。
- 编队：前 2 后 3，五人，3 套预设，推荐阵容，支持点击与拖拽（桌面实测，触控代码级）。

## 战斗引擎

- 固定 100ms 逻辑步；mulberry32 种子随机，同配置同种子同结果。
- 能量：初始 20、上限 100、普攻命中 +12、受击回能；大招 100 可手动或自动；1/2/3 倍速；90 秒上限。
- 伤害公式：攻击×倍率×100/(100+防御)×暴击(5%/150%)×阵营倍率×波动 0.95–1.05×(1−减伤≤70%)。
- 状态：护盾（上限最大生命 60%、同源取高）、嘲讽、眩晕、沉默、减速、灼烧/中毒（各 3 层）、攻防增减、治疗削减、易伤、减伤、分担。
- Boss 机制：荆冠巨獾蓄力横扫（可被硬控或集火破蓄 CAST_BREAK 6%）、锅炉王护盾/破盾虚弱/召唤维修机、潮眼巨蟹海盐治疗削减/退潮减速、失眠观星者 70%/35% 分身与可/不可打断流星。

## 内容与系统（均真实结算、写入存档）
