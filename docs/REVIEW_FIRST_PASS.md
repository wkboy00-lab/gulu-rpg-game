## 存档专项发现（待修，发布前重点）

1. validateSave 接受只有schemaVersion/res的残缺对象，也接受gold为字符串。缺少英雄等级、数组/对象形状、编队唯一性、装备归属/数值、时间戳等完整校验。导入确认后可能进入不可渲染状态。
2. migrate 使用 Object.assign(d,st) 先覆盖默认嵌套对象，再试图补默认值，实际上可能丢失默认字段。实测 settings:{sfx:true} 后 speed 仍是 undefined。
3. 导入提示说“导入前已自动保存当前存档”，但没有独立可恢复备份槽；导入后 main 被覆盖。不能把现有逻辑称为可恢复备份。
4. boot 未对加载数据执行 validateSave；读取异常/不兼容档回落新档后会自动保存，存在覆盖坏档取证数据的风险。
5. 本轮仅修写入确认、错误反馈、切后台尽力保存，不改变schema。pagehide是尽力保存，浏览器强制结束时不保证完成；需要后续备份与恢复方案。
