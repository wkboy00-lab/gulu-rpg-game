# 存档结构

- 存储：浏览器 IndexedDB，库名 `gulu-expedition`，对象表 `save`，键 `main`。
- `schemaVersion = 1`；加载时做迁移合并与合法性校验（拒绝负资源、未知英雄、重复装备实例 ID）。
- 保存时机：关键操作后自动保存（约 250ms 防抖聚合）；整页刷新自动恢复。
- 设置页提供：导出 JSON、导入（校验通过才覆盖，导入前逻辑备份）、重置存档（二次确认）。
- 主要字段域：资源（res）、英雄等级/星级/技能与碎片、装备实例、编队与 3 套预设、主线星级与章节奖励、塔进度、副本每日次数、任务与活跃度、签到、邮件、招募保底计数、挂机时间戳与速率锚点、模拟充值中心（钱包/流水/首充/累充/月卡年卡/基金/战令/礼包）、外观拥有与穿戴、星尘季进度与兑换计数、训练竞技场积分/次数/战绩、迷雾远征进行态、剧情已读、设置项。
- 每日重置按游戏日（Asia/Shanghai）执行：副本次数、竞技场次数、签到、月卡/年卡日领标记、模拟钱包每日补领标记。
- 本地存档为客户端校验，不宣称服务端级防作弊。
