# 五人战斗 v1（2026.11.03-team1）

独立战斗预览：主城 → 推图 1-1 → 五人队伍战斗 → 结算面板 → 返回推图。
基线为 city5（`preview/city5-20261103`，提交 c425bc50），本分支
`preview/battle-team-20261103` 自 city5 提交新建，不动 main、不合并 PR、
不改仓库可见性与 Pages 发布源，不覆盖 city3 / city4 / city5 / battle-taidun-v4
的既有预览入口与存档。

版本：`APP_VERSION='2026.11.03-team1'`，设置页标签「主城 v4 · 公会大厅 v5 ·
五人战斗 v1」，页内另有只读调试钩子 `window.TEAM1_DEBUG`（版本号与战斗状态，
仅供实测，不参与玩法）。

## 基线（city5，实测确认）

- 主城 CTA「出发冒险」→ 推图；1-1（g=0）默认解锁，`STAGE_DEF[0]=[["E01",3]]`，
  3 只困困史莱姆 Lv.1，`stageReward(0)` = 金币 120、经验 60，无书/钻石/券；
  星级按存活人数：5 人 3 星、4 人 2 星、否则 1 星。
- 默认编队 5 人：苔盾、星盔、荷铃、叶弦、铜哨，前 2 槽前排。
- 战斗引擎为推图/爬塔/竞技场/副本/公会 Boss/试炼共用的同一套引擎，
  200ms interval，`stepBattle(100)` 步进，含暴击随机数；`finishBattle` 有
  `BT.over` 守卫，`quitBattle` 不结算。
- 存档：localStorage 键 `gulu-mtstyle-v1`，`?savekey=` 隔离，city4 的
  `commit()` 回滚与坏档保护全部保留；`validateSave` 校验 res/formation/heroes。
- 战场 UI：两栏头像、血条、技能横幅、日志、暂停/速度/跳过/撤退；结算
  只有 toast，无结算面板。

## 本轮差异（相对 city5）

1. 战斗只保留普攻、主动、被动。删除 `energy` 字段与全部能量增减、整个
   `doUlt` 函数及其调用点、能量条与相关文案；鳍刃击杀能量块连同
   wall-clock `setTimeout` 一并删除；E09 汲取行删除。`HEROES` 的 `ult`
   名称字段与存档 `sk.ult` 保留作原始资料与兼容，不再被战斗与界面读取。
   文件内「大招」「能量」「doUlt」「bar en」「u.energy」计数均为 0。
   影响范围：共用引擎的所有战斗（推图/爬塔/竞技场/副本/公会 Boss/试炼）
   一并只剩三技能；灯羽主动原效果依赖已移除的机制，本轮记日志说明未实现。
2. 命中帧结算。新增 `BT.pending` 待命中队列：普攻在出手后 400ms 命中帧
   结算；苔盾主动在 460ms 前顶帧结算嘲讽 2 秒 + 12% 护盾（冷却仍从出手
   起算 8 秒）；攻击者在命中前倒下则该次攻击取消，目标提前倒下不转移
   伤害。敌人普攻同样走待命中，种族特效在命中时触发。
3. 苔盾分层战斗动作。复用 city5 已有的 `ART.taidun` 5 图层（全部取自
   原图像素，v3.1 修复版）与眼睑几何/支点/关键帧；姿态由战斗时间驱动：
   前摇（<200ms）→ 突进（<400ms）→ 接触（<600ms）→ 回位（<900ms），
   主动为前摇（<460ms）→ 持盾（<1000ms）。突进距离首次渲染时由
   `.tfig` 右缘与目标 `.figimg` 左缘实测，`px = gap + 4`，夹取 18–120。
   受击为盾牌上抬的 `hurt` 类，被动触发为闪光 + 治疗浮字，护盾气泡按
   `shield > 0` 显示/隐藏。暂停时 `#bstage.paused` 冻结全部 CSS 动画。
   其余 4 名英雄与敌人的旧整图浮动已停用，全部为静态占位。
4. 苔盾被动改为受伤触发（验证中发现并修复的基线问题）。city5 基线里
   被动只在苔盾自己行动的回合检查，残血被连续命中打死时永远不触发；
   现改为 `hurt()` 内首次跌破 35% 立即回 10% 生命、每场一次、恰好阈值
   不触发，与 v4 样板验证过的规则一致；致死一击也会先触发被动再判定
   倒下。行动回合的旧检查块已删除。被动日志行「被动「虽然害怕」：恢复
   10% 生命（本场一次）」。
5. 战斗日志不再冻结（验证中发现并修复的基线问题）。基线 `updateStage`
   只比较日志条数，40 条封顶后条数恒为 40，日志区从此不再刷新；现改为
   比较日志全文，内容变化即重绘。被动触发等中后期事件现在看得到。
6. 伤害浮字确定性。横向抖动由 `Math.random()` 改为确定性轮转，播种随机数
   下自动与跳过结算可精确复核；其余随机数只剩暴击与战后 30% 装备掉落，
   均在战斗序列内。
7. 结算面板。`startStage` 的 `onEnd` 加 `settled` 守卫；胜利时
   `afterBattleWin` 改用 `commit()` 包裹（保存失败则奖励与星级回滚），
   随后显示星级/存活/奖励明细/保存状态 +「返回推图」「再打一次」；
   失败时显示失败面板（不扣资源、不记星级）+ 同样两按钮；`backToMap()`
   隐藏 overlay 并回推图。`finishBattle` 的 `BT.over` 守卫 + `settled`
   守卫双重保证单次结算；刷新后奖励不重复。

## 数值（保留原游戏公式，输入取自编队状态）

- 队伍属性用 `heroStats`（有效等级 + 星级/觉醒倍率 + 装备加成），因此
  队伍里的苔盾 maxHp 为 2131（不是 v4 样板裸数值 1900）；公式与 city5
  完全一致，未改动。按 2131 与攻击 112 换算：普攻公式值约 102（实测
  日志出现 97，含暴击与伤害浮动）、主动护盾 256（12%）、被动阈值 745
  （35%）、被动回血 213（10%）。
- v4 样板验证过的裸数值（普攻 91、敌攻 34、护盾 228、被动 190）仍是
  同一公式在裸属性下的结果，样板本身未动。
- 1-1 奖励：金币 120、经验 60；星级按存活人数；战后 30% 概率掉一件装备
  （原规则保留）。

## 存档

- 正式预览继续共用 `gulu-mtstyle-v1`（与 city5 同源、进度延续）；测试用
  独立 `?savekey=` 键，不碰主存档。旧档可直接加载，本轮未改存档结构；
  `sk.ult` 字段保留兼容，界面与战斗不再读取。
- 胜利奖励经 `commit()` 保存，保存失败回滚并提示；战中刷新不结算、不记
  奖励、不记进度；结算后刷新奖励不重复。

## 未完成 / 占位（明确说明，不宣称已推广）

- 只有苔盾有分层动作（待机/前摇/突进/接触/受击/回位/主动/被动）；
  其余 11 名英雄无分层动作，在队伍战斗中为静态立绘占位；敌人为静态
  原画占位（有受击抖动、倒下变灰，无分层动作）。
- 灯羽主动「今晚的预言」原效果依赖已移除的能量机制，本轮未实现（点按
  只记日志）；鳍刃被动（击杀得能量）随能量机制一并移除；星盔被动
  （破盾回血）与铆牙被动（开场护盾）从未在团队引擎实现，本轮未补。
  四人均不在默认编队（星盔在编队内，其主动「站稳一点」正常工作）。
- 声音为既有合成音效；队伍外系统（召唤/养成/爬塔/竞技场/副本/公会）
  除共用战斗引擎的三技能对齐外未改动。
- 手机真机点按与实机流畅度未测试；录屏与点按验证均为桌面 Chrome 模拟。
