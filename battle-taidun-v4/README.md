# 苔盾 v4 · 战斗样板（2026.11.03-taidun-v4）

苔盾 vs 困困史莱姆的完整可玩战斗。先做一个英雄的样板，验收通过后再扩展。

## 玩法与规则

- 只有三种技能：**普攻「木盾撞击」**、**主动「看这里」**、**被动「虽然害怕」**。
  本样板内没有任何其他技能机制，界面与逻辑中也没有相关内容
  （`tests/engine.test.cjs` 有回归检查）。
- 数值与原游戏一致（Lv.1，确定性模式：无暴击、无浮动）：
  苔盾 1900 血 / 攻击 100 / 护甲 60；史莱姆 700 血 / 攻击 55 / 护甲 10。
  普攻 91（`100×100÷110` 取整）；敌人普攻 34（`55×100÷160` 取整）；
  主动护盾 228（最大生命 12%，持续 5 秒，嘲讽 2 秒，冷却 8 秒，不造成伤害）；
  被动每场一次，首次低于 665（35%）时恢复 190，恰好 665 不触发。
- 结算只在命中帧发生一次：伤害、血条、伤害数字、命中特效、受击反应、
  护盾变化、被动触发都由同一个命中事件驱动。
- 主动的冷却从出手时起算，护盾与嘲讽在盾牌前顶帧（460ms）结算。
- 暂停冻结一切：动作、粒子、浮字、冷却、状态计时（逻辑步长 20ms，
  无任何 wall-clock 计时器）。速度 1×/2×/3× 只改变每帧逻辑步数。
  跳过战斗用同一逻辑步进快进到战斗结束，不跳过任何一次结算，
  结果与正常播放一致（浏览器实测：跳过两次的结果相同，
  3× 自动打完的结算与跳过完全相同）。
- 本页不读写任何存档（无 localStorage / IndexedDB），不影响原游戏与主城预览。

## 分层动作

5 个图层，全部取自原图像素（v3.1 修复版，静止合成与原画差异 1.1）：

| 图层 | 来源 | 支点 |
|---|---|---|
| 身体（含龟甲） | 原图像素，遮挡区原图扩散补画 + 高频纹理 | 50% / 82% |
| 前腿 | 原图像素 | 27% / 71% |
| 头部 | 原图像素 | 36% / 48% |
| 盾牌与持盾手 | 原图像素 | 57% / 60.5% |
| 持锤手与木锤 | 原图像素 | 31.5% / 51% |

旧 AI 重绘层备份在 v3 目录的 `layers-ai-backup/`（已弃用，未使用）。
图层文件在工作目录 `layers/`；本单文件已全部内嵌。

动作：待机（呼吸、眨眼、头部微动、盾牌与持锤手轻摆，脚底落地有阴影）、
普攻前摇（下蹲、盾牌后拉、持锤手后摆）、出手（突进距离每次由盾缘攻击点
与受击点实时计算）、命中（命中顿帧 60ms、冲击碎屑、伤害数字、敌人受击
挤压 + 击退）、受击（身体后仰、盾牌上抬，与当前动作叠加）、回位、
主动（立盾、护盾气泡建立/受击/击破/到期四种状态各不相同、嘲讽小气泡）、
被动（绿叶飞散 + 治疗数字，不遮挡战场）。敌人同样有待机、风摇、接触突进、
受击、倒下动作，突进距离也实时计算。

接触点（实测图层不透明像素）：盾缘在图层宽度 95% 处（最右不透明像素
94.9%）；史莱姆受击点在图宽 11% 处（最左不透明像素 11.2%）。
命中时盾缘落在受击点 +4px（浏览器三尺寸实测误差 ≤10px）。
